# Source: https://en.wikipedia.org/wiki/Image_file_format (retrieved 2026-09-04)

An image file format is a file format for a digital image. There are many formats that can be used, such as JPEG, PNG, and GIF.

The data stored in an image file format may be compressed or uncompressed. If the data is compressed, it may be done so using lossy compression or lossless compression.

The High Efficiency Image File Format (HEIF) is an image container format that was standardized by MPEG on the basis of the ISO base media file format.
