# Source: https://en.wikipedia.org/wiki/Metering_mode (retrieved 2026-09-04)

In photography, the metering mode refers to the way in which a camera determines exposure. Cameras generally allow the user to select between spot, center-weighted average, or multi-zone metering modes.

With spot metering, the camera will measure only a very small area of the scene (1–5% of the viewfinder area). By default this is the centre of the scene.

In this metering mode, the camera uses light information from the entire scene and creates an average for the final exposure setting, giving no weighting to any particular portion of the metered area. In some situations, such as a snowy landscape, this mode will result in underexposure by 2 f-stops or more, because the metering system attempts to darken an excessively bright scene.
