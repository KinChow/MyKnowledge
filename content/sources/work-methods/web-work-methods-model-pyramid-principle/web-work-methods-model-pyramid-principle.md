The Minto Pyramid Principle, originated by Barbara Minto, is adopted in management consulting to assist in presenting complex information. The principle suggests that people's ideas should be communicated in a pyramid format in which ideas are organized top-down, starting with a main idea that is a high-level summary of supporting key ideas, each of which is derived from further supporting sub-points. Minto published the book The Pyramid Principle: Logic in Writing and Thinking in 1985.
