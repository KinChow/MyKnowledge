# 注意力机制与替代方案

## 一句话结论

标准自注意力的 Q·Kᵀ 全连接交互使复杂度为 O(N²·d_k)，而 N（上下文长度）可达数百万 token，因此随序列变长，注意力成本会迅速压过线性增长的 FFN 成本。课程给出两条应对路线：一是系统工程/常数因子优化（FlashAttention 等重新排列运算、减少内存传输，约 2 倍提速，但仍是二次方）；二是架构级改造，核心思想是"乘法的结合律"——（暂时）去掉 softmax 后把 (Q·Kᵀ)·V 重排为 Q·(Kᵀ·V)，把对序列长度的依赖从 N² 变成 N·d_v·d_k（d 只有几千几万量级），由此得到线性注意力、Mamba2、GatedDeltaNet 这类"并行训练 + 循环推理"的状态空间模型，以及 DeepSeek 稀疏注意力（DSA）"轻量索引器 + 子集全注意力"的另一条路线。课程明确强调：到目前为止还没有人真正在大规模上验证过完全线性时间的 attention，所有经过实战检验的都是混合架构。

## 核心概念

- **注意力的 O(N²) 问题**：Attention 是"所有不同位置之间的全连接"，其计算复杂度为 N 平方乘以 DK（Q·Kᵀ 的乘法）；N 是上下文长度，可达数百万，所以随序列长度增长会迅速超过线性增长的 FFN 成本。
- **乘法结合律**：softmax（mask/归一化）是阻止重排的关键；若暂时去掉它，Q·Kᵀ·V 可以重新排序为 Q·(Kᵀ·V)，二次方依赖从 N 转移到 d_v·d_k（隐藏维度，通常只有几千几万的数量级，无人放一百万个坐标）。
- **常数因子优化 / FlashAttention**：不改变 O(N²) 复杂度，而是重新排列注意力运算、减少内存传输开销，在注意力性能上获得"非常非常显著"的提升（约 2 倍）。
- **线性注意力 / RNN 对偶性**：去 softmax 后，Kᵀ·V 的逐步累积看起来就像一个 RNN——固定大小状态 S 从左到右增量更新；训练用并行的密集形式，推理用序列的循环形式，两全其美。
- **门控状态空间模型**：Mamba2 在状态更新上加"门控 Gamma（关于 t）"；GatedDeltaNet 再加第二个门控 BetaT，并用"单位矩阵 − β·K·Kᵀ"投影器做 delta 式擦除。经验法则：只要门控项不依赖状态，就能保留"并行操作（训练）+ 串行操作（推理）"的对偶性。
- **稀疏注意力 DSA（DeepSeek Sparse Attention）**：用一个轻量索引器从长上下文中挑出一个比完整序列小得多的子集，只在该子集上做全注意力；索引器本身仍是非线性的，但可做得非常便宜（降维、低精度、小 W）。
- **混合架构**：目前所有大规模验证都来自"7 比 1""3 比 1"这类线性/循环层与完整注意力层的混合；随混合比例增加性能逐渐下降，过渡到纯 RNN 时明显下降。

## 工作机制

1. **动机**：主流供应商争相扩大 Context Window（对数尺度图），以支持更多知识、智能体等工作负载；同时 FFN 成本线性增长、Attention 二次方增长，曲线交叉后注意力成为长上下文的主要瓶颈。
2. **控制成本的两个方向**：一是局部注意力混合（"如果你每八层才做一次全局注意力，而其他层都用这种非常局部的注意力，那么成本就得到了很好的控制"）；二是系统工程/常数因子，即 FlashAttention（"重新排列了注意力运算，使其对系统更友好，从而最大限度的减少内存传输开销"）。
3. **核心推导**：标准注意力 = 用 Q 和 K 做全连接式交互 → mask 归一化 → 与 V 相乘得输出。去掉 mask 后，利用乘法结合律把 (Q·Kᵀ)·V 重排为 Q·(Kᵀ·V)，复杂度从 N²·d_k 变为 N·d_v·d_k。
4. **RNN 视角**：把 K 和 V 相乘后更新状态 S 并累加（"逐步的乘起来并累加我的KV"），再与 Q 相乘得到输出，即稠密运算的 RNN 形式；推理时状态大小固定、一直向前传递，训练时可用并行密集形式。
5. **Mamba2**：受 LSTM 启发，加一个无状态的"门控 Gamma(t)"，只依赖当前输入，决定把多少当前状态传递到未来；仍然保有"稠密矩阵乘法（训练）/ 循环形式（推理）"的对偶性。
6. **GatedDeltaNet**：在 Mamba2 基础上加第二个门控 BetaT（决定是否接收当前信息、是否加进状态），并把更新做成"擦除已进入状态的当前 Key 方向"的 delta 投影（蓝色项"单位矩阵减去BetaT乘以KKKT的转置"，本质上是把 KT 维度投影出来）；该投影器在快速权重编程、测试时训练等场景被反复重新发明。
7. **混合架构实证**：随"非全注意力（RN）层"比例增加，性能逐渐下降；最佳架构（如 GatedDeltaNet 变体）在低混合比例时基本看不到性能损失，超过临界点后在长上下文任务上显著下降，过渡到全 RN 时明显下降——单件检索（所有长上下文架构都明确针对优化的任务）与问答任务都呈类似趋势。
8. **DSA 稀疏注意力**：把正常 query/key 传入索引器，索引器算 query 和 key 的内积、得出每个位置的激活值，再通过 top-k 把排名靠前的位置纳入注意力计算，最后在小子集上执行常规全注意力。训练时不需要索引器（先训练普通 transformer），在独立于预训练的长上下文扩展阶段再引入并让模型适应索引器，计算成本本身相当低；预填充与解码两阶段都相对上一代显著扩展。
9. **现状与展望**：大部分经过测试的方法都收敛到"非常类似 LSTM 的线性注意力循环形式"；未来更像把所有技巧（局部注意力、线性注意力、稀疏注意力、低精度等）整合进复杂架构，并用后训练让模型管理自己的上下文（压缩、摘要）。

## 示例或代码

- **复杂度数字**：标准注意力"复杂度是N平方乘以DK"；重排后依赖 N·d_v·d_k，而 d"通常只有几千几万的数量级"、"没有人会在隐藏层维度里放一百万个坐标"。
- **FlashAttention 实测**：BestPi Torch（蓝线）在较短序列长度时性能约"每秒30到40万亿次浮点运算"，使用 FlashAttention 后"就能获得两倍这样巨大的性能提升"；某些规模下"不再实力化巨大注意力矩阵"才能继续运行（速度会慢些）。
- **MiniMax M5**：规模相当大、性能相当高的中国开源模型，使用"7比1的混合架构"，即"7个线性注意力层加上一个完整的Moth注意力层"；对上下文长度的依赖"大部分是线性的"（因有 softmax 层不是完全线性），"它可比肩OP03或DeepSeaCar1等强模型很有竞争力"。
- **Nemotron 3**：把 Mamba2 作为轻量级层、时不时用大的 softmax 注意力，以各种方式交替管理推理成本和表达能力；由于大量 Mamba2 层，"拥有相当不错的吞吐量和相当大的上下纹长度"。
- **Qwen3.5 / Qwen Next**：使用"3比1的门控Delta注意力混合结构"；随上下文长度不断增加，"Quint Next比Quint 3的解码吞吐量要高很多"，且混合架构对性能影响不大。
- **DSA**：DeepSeek-V3.2（与 Claude 4.5 Sonnet、Gemini 3 等前沿模型同一水平）；"你实际上会引入这个轻量级索引器"，"在一个独立于预训练的扩展阶段里训练模型去适应这个索引器"；GLM5 也采用 DSA，完整 DSA 训练相对全注意力的"性能上的损失其实非常小"，哪怕在 RNN 架构难搞定的长上下文检索任务上。
- **消融研究**（ByteDance Seeded 与 UC Santa Cruz，比较 Mamba2、Gated DeltaNet 等）：虚线为全注意力性能，随非全注意力层数量增加性能逐渐下降。

## 常见误区

- 误区：FlashAttention 解决了长上下文问题。澄清：它只是"常数因子的系统优化"，"这没解决二次成本问题"；处理"500万""1000万个Token"时这些技巧可能就不够用。
- 误区：线性注意力（并行形式）与循环形式效果应该完全一样、没有损失。澄清：从带 softmax 的全注意力到线性形式"第一步是有损的"（去掉 softmax）；此后线性形式与循环形式之间的等价关系才是精确的。
- 误区：DSA 索引器是线性时间。澄清："这不是线性时间"，索引器仍需在全对全注意力上做 Query/Key 内积，成本不是线性的；但可通过降维、低精度、让 W 非常小等把常数因子做便宜，且 top-k 受上限约束——"有时候别太纠结于二次形还是非二次形，常数因子真的真的非常重要"。
- 误区：状态模型和 LSTM 类似，硬件训练优势会消失。澄清：由于线性注意力存在被很好理解的对偶性，可从循环形式转换到更密集的矩阵乘法形式，"那个权衡现在基本上已经被解决了"；真正剩下的是表达力权衡——有限状态必须把所有信息带过去，"相对于直接携带所有信息来说，你肯定会丢失一些信息"。
- 误区：线性/去掉 softmax 会让训练不稳定。澄清：讲师未听说有文献记载线性 softmax 会导致很多注意力问题，反而认为"这实际上会改善架构的稳定性"。

## 待验证项

- 完全线性时间 attention 是否能在超大规模验证有效——课程明确"还没有人真正在大规模上验证过"，"所有内容都是混合架构"。
- 混合层比例的更优配置：目前缺乏高质量控制变量研究，仅一项 ByteDance Seeded 与 UC Santa Cruz 研究，结果"有些结果确实有点乱"。
- DSA 索引器的实现细节（降维/低精度）、top-k 上限 K 的选取、以及"短上下文预训练→长上下文扩展阶段引入索引器"的通用性。
- 低精度注意力：FP4 注意力"绝对是可能的"，但讲师"不知道是不是真的有很好的方法能在FP甚至某种更低精度下实现全的tension"。
- "小状态难以压缩大上下文"是否有一天能无权衡——讲师认为"那还很遥远"。
- 本讲 Q&A 口语部分存在较多转写误差（模型名、专有名词如"Moth/Moft/Mobsk"等），具体名称与数字需以原始论文为准。

## 详细章节

### 为什么需要更长的上下文（动机）

供应商竞相提供越来越大的 Context Window（对数尺度图）；随着序列长度增长，FFN（线性）与 Attention（二次方）成本曲线交叉，注意力成为主要瓶颈。课程指出"Attention是所有不同位置之间的全连接""它是二次方的"，"随着序列变长，Attention现在越来越成为一个大问题"。

### 标准注意力的 O(N²) 复杂度

注意力运算 = Q、K、V 三个矩阵；Q·Kᵀ 做全连接式交互（复杂度 N 平方乘以 DK），mask 归一化后与 V 相乘。若无 mask，可重排括号改变二次方落在哪一部分——从 N² 转移到 N·d_v·d_k。

### 常数因子优化：FlashAttention

FlashAttention 不改变复杂度，而是"重新排列了注意力运算""最大限度的减少内存传输开销"，短序列从约 30–40 万亿次浮点运算/秒提升约两倍；某些规模下只有不实例化巨大注意力矩阵才能继续运行。

### 线性注意力：乘法结合律与 RNN 对偶性

核心思想是"乘法的结合率"。去掉 softmax 后，(Q·Kᵀ)·V 与 Q·(Kᵀ·V) 等价；后者在自注意力情况下"看起来就像一个RNN"——从左到右增量更新固定大小的状态 S（"逐步的乘起来并累加我的KV"）。训练用并行密集形式、推理用循环形式，"所以现在你能两全其美"。但"这种方法是线性的，效果不好"，只是讨论起点；MiniMax M5 用 7 比 1 混合（7 个线性注意力层 + 1 个完整注意力层）证明了基础线性注意力加完整二次连接可在大规模有效。

### Mamba2：门控状态空间模型

线性注意力的主要问题是"总是在向前传递状态"，受 LSTM 启发加入门控 Gamma(t)（无状态、只依赖当前输入），决定传递多少状态到未来；仍保留稠密矩阵乘法（训练）与循环形式（推理）的对偶性。Nemotron 3 把它用作轻量级层，偶尔穿插大的 softmax 注意力。

### GatedDeltaNet：双门控与 delta 投影

在 Mamba2 状态更新上加第二个门控 BetaT（控制是否接收当前信息），并用"单位矩阵减去BetaT乘以KKKT的转置"作为投影器，擦除已进入状态的当前 Key 方向（不只是放东西，还想清除已输入的当前 Key）。该投影器在快速权重编程、测试时训练中被反复重新发明。Qwen3.5 / Qwen Next 使用 3 比 1 门控 Delta 注意力混合结构，解码吞吐量随上下文长度显著领先。

### 混合架构的实证与消融

随非全注意力（RN）层比例增加，性能逐渐下降；Gated DeltaNet 等最佳架构在低混合比例下几乎无性能损失，超过临界点后在长上下文任务上显著下降，过渡到全 RN 时"所有架构的性能都会出现非常明显的下降"；单件检索与问答任务趋势类似。

### 稀疏注意力（DSA）：轻量索引器 + 子集全注意力

DeepSeek-V3.2 的 DSA：正常 query/key 传给轻量索引器 → 内积打分 → top-k 选位置 → 在小子集上做全注意力。训练不需要索引器，先训普通 transformer，在独立于预训练的长上下文扩展阶段引入并适配索引器。GLM5 采用 DSA，完整 DSA 训练相对全注意力的性能损失非常小，长上下文检索任务亦如此。注意：索引器本身不是线性时间，但可做得非常便宜。

### 状态模型的权衡与未来方向

与坚持全注意力（全连接极其强大、非常容易训练）的 Transformer 相比，状态模型的缺点是表达力——有限状态携带所有信息"肯定会丢失一些信息"；"如果你想要一个非常小的状态，那你就很难把大上下文中的所有信息都压缩进去"。未来方向可能是把局部注意力、线性/循环层、稀疏注意力、低精度等技巧整合进复杂架构，并用后训练让模型管理自己的上下文；"至少线性时间Attention已经大量收敛到类似LSTM或线性注意力的架构中"。
