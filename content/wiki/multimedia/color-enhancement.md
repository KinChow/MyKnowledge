# 颜色增强

## 一句话结论

颜色增强（Color/Saturation Enhancement）通过放大色度分量使画面更鲜艳：饱和度描述颜色偏离中性灰（R=G=B）的距离，HSV 空间（HSL/HSV 是 RGB 模型的柱面坐标表示）只调 S 分量即可增强/减弱饱和度而不影响明度与色相。工程上先对异常区域（暗部彩噪/伪彩）**降**饱和度，再对正常区域自适应**增**饱和度，并对肤色等敏感色做保守选择性增强；难点是整图统一增强在混合场景难以两全，需引入语义分割（ML）差异化调色。

## 核心概念

- **饱和度（Saturation）**：颜色偏离中性灰的距离；HSV 中 S 越高越纯，S=0 为灰度。
- **HSV/HSL**：RGB 模型的柱面坐标表示（色相 Hue/饱和度 S/明度 Value 或亮度 L），便于只调饱和度。
- **低饱和成因**：AWB 残余色偏、降噪压低色度、CCM 去饱和矩阵、低饱和场景/曝光不足。
- **增强策略**：先降异常（近灰度滤波抑彩噪），再自适应增（按亮度/平坦度/噪声），敏感色保守。
- **溢出控制**：增强后 RGB 越界需色域裁剪/柔化，避免色相翻转。

## 工作机制

1. **分析**：统计图像饱和度分布（最大饱和度统计），确定当前画面色彩丰富度基线。
2. **降异常**：对接近灰轴、亮度低的像素（暗部彩噪/伪彩）降低饱和度（近灰度降饱和度滤波）。
3. **增强**：在 HSV 域对 S 做非线性增益（自适应：亮部/平坦区增强、暗部/高噪声区保守），或对 Cb/Cr 施加增益 + 亮度补偿。
4. **选择性增强**：肤色（H 20-50°）保守、嘴唇/绿叶/蓝天小幅增强（肤色检测限定区域或 3D LUT 分区调色）。

## 示例或代码

```text
HSV 饱和度增强：
  HSV = RGB → HSV 转换
  S' = S^γ 或分段曲线（非线性增益）
  RGB' = HSV → RGB 转换（含溢出裁剪，防色相翻转）

近灰度降饱和滤波：
  if 饱和度 < 阈值 and 亮度 < 阈值:   # 暗部彩噪
      S *= 0.3                        # 向灰度压缩
```

## 常见误区

- **"增强饱和度越多越好"**：过度增强导致色块/色阶断裂，暗部彩噪被放大；需自适应控制。
- **"在 RGB 域直接调饱和度"**：易产生色相漂移；HSV 域只调 S 更可控。
- **"肤色也要加强"**：肤色增强要保守（H 20-50°），过度会失真偏橙；用户最敏感。
- **"整图统一增强就行"**：人像+风景混合场景难以两全，需语义分割差异化调色。

## 详细章节

### 背景

#### 饱和度的解释

饱和度（Saturation）描述颜色的鲜艳程度，即颜色偏离中性灰（R=G=B）的距离。HSV 空间中饱和度 S 越高颜色越纯，S=0 为灰度。饱和度增强（Saturation Enhancement）通过放大色度分量使画面更鲜艳、更有视觉冲击力，是手机相机/显示调色的常用手段。

#### 色彩饱和度Rg

饱和度也可用色度比（如 R/G、B/G）相对灰点的偏离来度量。在相机 ISP 中常定义饱和度相关指标：统计图像中像素色度偏离灰轴的程度，或定义"色度值"（如 max(R,G,B) - min(R,G,B)），用于量化当前画面饱和度并指导增强强度。

#### 低饱和度的原因

- 光源色温偏高/偏低导致整体偏色，AWB 校正后残余色偏降低观感饱和度
- 弱光/高 ISO 下噪声增大，降噪（尤其色度降噪）会压低色度，画面发灰
- 镜头/传感器光谱响应导致颜色偏淡
- 色彩校正（CCM）为控制色噪而采用去饱和矩阵
- 画面本身是低饱和场景（阴天、雾天），或曝光不足

#### 色彩增强与HSV颜色空间

HSV（色相 Hue/饱和度 Saturation/明度 Value）把颜色分解为三个直观分量，非常适合做色彩增强：只调整 S 分量即可增强/减弱饱和度而不影响明度与色相，调整 H 可做色相偏移（风格化），调整 V 可配合明度。相比在 RGB 域直接运算，HSV 域增强更可控、不易产生色相漂移。

#### 色彩增强的作用

- 提升画面鲜艳度与视觉吸引力，符合用户审美偏好
- 弥补弱光/降噪/色彩校正造成的饱和度损失
- 特定场景增强（食物、风景、人像肤色）提升成片质感
- 风格化（电影感、游戏感）调色

### 方法

#### 降低异常色彩的饱和度

当画面出现不自然的彩色噪声或异常彩色边缘（如高 ISO 暗部的红绿彩噪、紫边）时，需要先降低这些异常区域的饱和度，而不是一味增强，否则会把噪点/伪彩放大。

**近灰度降饱和度滤波**：对接近灰轴（低饱和度）的像素降低其饱和度：因为暗部噪声与伪彩通常饱和度低、亮度低。设置饱和度阈值，低于阈值的像素向灰度方向压缩（S 乘以小于 1 的系数），可有效抑制暗部彩噪而不影响正常色彩。实际常与亮度阈值联合（只处理暗部），避免影响亮部的正常色彩。

#### 饱和度增强

**最大饱和度统计**：统计图像中饱和度分布（如取饱和度直方图的高分位），确定当前画面的色彩丰富度基线，据此决定增强强度——画面已经饱和则少增强，偏灰则多增强，避免过度增强导致色块/色阶断裂。

**自适应的饱和度增强**：根据像素亮度、区域平坦度、噪声水平自适应调节增强强度：亮部与平坦区域可适度增强，暗部与高噪声区域降低增强（否则放大彩噪）；不同色相可给不同增益（如肤色敏感区保守、自然色可大胆）。目标是"该艳的艳、不该艳的不艳"。

**饱和度补偿计算**：增强饱和度的同时保持亮度与色相稳定：常用做法是在 HSV 域对 S 做非线性增益（如 S' = S^γ 或分段曲线），再转回 RGB；或直接对色度分量 Cb/Cr 施加增益并做亮度补偿。注意溢出控制（增强后 RGB 越界需做色域裁剪/柔化，避免色相翻转）。

#### 对肤色、嘴唇、绿叶和蓝天进行有效的色彩提升

针对用户敏感的颜色做选择性增强：肤色（H 约 20-50°）增强要保守且保持自然（过度会失真/偏橙），嘴唇/绿叶/蓝天可在其色相范围内小幅增强。实现上常用肤色检测（YCbCr/HSV 阈值或 ML 分割）限定增强区域，或用 3D LUT 按色相分区调色，避免全局增强误伤肤色。

### 难点

结合机器学习技术，实现照片、游戏色彩增强。当前色彩增强是采用整图的处理；ML 中分割、识别后，对人、绿叶、蓝天等进行色彩增强。

- 整图统一增强在混合场景（人像+风景）中难以两全，需引入语义分割（ML）按物体类别差异化调色
- 实时性：移动端需在有限算力下完成分割/增强，神经网络要轻量化
- 调参复杂度：饱和度/色相/亮度多维度参数与场景、噪声、降噪耦合，需大量调试

### 未来展望

* 为手机移动端用户带来更加出众的游戏视效。改善游戏的场景细节、色彩饱和度和对比度。
* 食物色彩增强后，食物更有美感。
* 语义感知的智能色彩增强（人/景/物分别调色）、游戏与摄影融合的实时色彩风格化是主要方向。
