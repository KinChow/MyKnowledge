# Transformer 架构组件

## 一句话结论

现代"密集注意力"Transformer 的骨架高度收敛：一个**残差流**（residual stream）贯穿整个网络，每个 block 依次执行层归一化 → 多头注意力 → 加回残差流 → 层归一化 → FFN/GLU → 加回残差流。相比原始 Transformer，现代模型几乎一致地做出三处改变：把层归一化从残差流内移到残差流外（pre-norm，普遍改用 RMSNorm）、用门控线性单元（GLU，如 SwiGLU/GeGLU）替代普通激活、用 RoPE 这类相对位置嵌入替代正弦/余弦绝对嵌入。超参数层面，FFN 与模型维度比率（非 GLU 约 4，GLU 约 2.67）、长宽比（模型维度/层数≈100）、多头（头维度×头数=模型维度）等，都是宽容且被广泛遵循的经验法则，真正难调的是系统利用率与训练稳定性而非这些架构选择。

## 核心概念

- **残差流（residual stream）**：贯穿整个网络的激活 X。注意力、FFN 各自计算出一个增量再加回残差流。层归一化的放置本质是在问：它应该留在残差流里，还是移到残差流之外。
- **前归一化（pre-norm）vs 后归一化（post-norm）**：原始 Transformer 把 LayerNorm 放在残差流内的子层之后；pre-norm 则把归一化放在每次子层计算之前、残差流之外。所有现代语言模型都把层归一化移出残差流。
- **RMSNorm vs LayerNorm**：LayerNorm 减去均值、除以方差、再缩放回来；RMSNorm 不减去均值/偏置项，只做缩放。现代模型基本都用 RMSNorm。
- **多头注意力**：有 H 个注意力头，标准做法是让头维度与头数满足"经验法则就是注意力头的维度乘以头的数量"等于模型维度（每个头维度 D/H）。这是经验法则，非铁律。
- **FFN 与门控线性单元（GLU）**：前馈网络 = 输入经两个矩阵变换。门控版本多一个门控矩阵 V：`激活(W·x) ⊙ (V·x)`，再投影回原维度。常见变体：SwiGLU（门控用 SiLU/Swish）、GeGLU（门控用 GELU）、ReGLU（门控用 ReLU）。
- **RoPE（旋转位置编码）**：把词向量按位置"旋转"，使任意两个嵌入的内积只依赖于它们的相对位置差，属于相对位置嵌入；2024 年之后大多数模型采用。
- **QK-norm 与 Z-loss**：两类训练稳定性技巧。QK-norm 在 q、k 相乘进 softmax 前加归一化；Z-loss 在损失里惩罚 softmax 归一化项 log z 偏离 0。
- **GQA / MQA**：分组查询/多查询注意力——减少键、值头的数量而保持查询头数量，换取推理成本与表达能力之间的权衡。

## 工作机制

1. **残差流承载信息**：Transformer 里有一个贯穿网络的 X（残差流）。每个子层先做一次计算（Attention 或 FFN），再把计算出的"增量"加回残差流，保证梯度/信号能沿残差路径直通。
2. **归一化放在哪**：原始论文把 LayerNorm 放在残差流内、子层之后（post-norm）。pre-norm 把归一化移到残差流之外、子层计算之前（可放在多头注意力之前，也可放在前馈网络之前）。这让 X 能从底部一路传到最终输出、梯度可直接穿过，同时提升稳定性与信号传播，因此被所有人采纳。
3. **注意力计算（QKV）**：先做预层归一化，乘以 QKV 权重得到 q 和 k，q、k 做矩阵乘法（点积注意力），对结果做 softmax，再"和v相乘得到加权平均在输出后面的结果"。Softmax 有两个对稳定性非常不利的因素——指数运算增长快、除法有风险。
4. **多头与头维度**：多个注意力头并行，每个头维度取 D/H；总维度保持与单头相同。
5. **位置编码**：Attention 是内积、在位置上独立——"你可以随意打乱它们的顺序"；若不加位置嵌入，则"Attention的结果是一样的"。RoPE 的做法是在注意力层（而非最底层）把 q、k 按序列位置做旋转，使内积只依赖相对位置；高频对旋转得快、捕捉邻近信息，低频旋转得慢、能捕捉长距离依赖。
6. **FFN / GLU**：串行块先算注意力再算 MLP。非门控 FFN 是 X·W → 激活 → 再投影；门控版本增加一个门控矩阵 V，`激活(W·x) ⊙ (V·x)` 后再投影回原维度。门控引入的额外参数量可通过把 FFN 维度缩到 2/3 来抵消。
7. **输出层稳定性**：输出侧 softmax 的归一化项 z 若很大或为 0 会造成数值爆炸；Z-loss 技巧在损失中加入 `log z` 平方惩罚项，让 log z 趋近 0（基于 softmax 过参数化、可被常数平移抵消而不影响输出本身）。

## 示例或代码

- **RoPE 的二维例子**：句子 "We,No"，"We,E这个单词出现在位置0"（不旋转），单词 No 在位置 1（旋转某个角度）。若把它们整体平移（We 在位置 2、No 在位置 3），We 旋转两个单位、No 旋转三个单位，两个向量之间的相对角度仍相差一个单位——内积只与相对位置有关。
- **高维实现**："最简单的方法就是反复将其简化为二维情况"——把向量切成两两一组、每组用不同旋转角度；一些低频对旋转得很慢，"因此能够捕捉长距离依赖关系"，高频对旋转快、捕捉"像它们是不是彼此相邻这样的信息"。最终嵌入形式为 `X·W·R`（旋转矩阵作用于词嵌入）。
- **FFN 比率**：非 GLU 模型经验值约为隐藏维度的 4 倍；GLU 把 FFN 维度缩到 2/3，"这意味着你最终会得到大约2.67这样的数值"；LLaMA 团队"任意乘以1.33得到大约3.5"；T5 是异常值，用了 64 倍乘数。
- **长宽比**：大多数模型的比率大约是模型维度 D 除以层数 N，等于 100 左右，即每层约 100 的宽度。
- **词汇量**：单语模型约 3 万；多语言/生产模型约十万到二十万。
- **算力占比**：归一化类操作"尽管它们只占计算量的0.17"，但由于内存搬运，"它们可能占到运行时的25"（小型模型上尤其严重），这也是改用 RMSNorm 的动机之一。

## 常见误区

- **误区：post-norm 一定在残差流里。** 澄清：可以"把层规一化移到了计算之后"且仍在残差流之外，Grok/Jamba 和 Gemma2 等新模型就采用这种"残差流外的后归一化"；还有模型在前后各放一个（双归一化）。
- **误区：RMSNorm 表达力弱于 LayerNorm、是次优选择。** 澄清：转录明说层规一化"比RAMS norm更具表达力"、且"真的没有理由必须使用RAMS norm"；但 RMSNorm 实际"表现效果和层规一化一样好"，且减少内存搬运带来免费性能提升。
- **误区：必须用 GELU/SiLU 这类"现代"激活函数。** 澄清："你可以只用相当普通的激活函数来构建和训练一个语言模型"，Chinchilla 用普通激活也能训练出性能合理的模型；GPT-3 甚至用平方值激活。
- **误区：RoPE 是绝对位置嵌入。** 澄清：RoPE 属于相对位置嵌入，靠旋转使内积与绝对位置无关、无交叉项——这与正弦/余弦嵌入不同，后者"也不是纯粹的相对位置嵌入"。
- **误区：多头注意力必须满足"头维度×头数=模型维度"。** 澄清：这是"经验法则"，并不是必须的，头维度与模型维度比例在 1 附近有一个宽的平坦区域，可以偏离。
- **误区：权重衰减是正则化、控制过拟合。** 澄清：转录指出"权重衰减实际上是一种优化干预"，其收益"而这通常发生在我们衰减学习率的时候"，不一定是恒定学习率。
- **误区：FFN 比率必须精确取值。** 澄清：Kaplan 2020 扫描显示 2.6 到 4 之间是一个平坦盆地，这个超参数表现相当好、非常平坦，选这些数字都没问题。

## 详细章节

### 残差连接与归一化的位置（pre-norm vs post-norm）

原始 Transformer 论文里"层规一化是放在所谓的残差路径上的"，即残差流内的 post-norm。pre-norm 把归一化移到残差流之外、子层计算之前。动机分两层：最初是为了去掉训练预热（warmup）并改善收敛——在无预热时也能得到好得多的收敛效果；更深层的理由是保持残差流干净——X 从底部一路传到最终输出，梯度能在反向传播中直接穿过，梯度传播简单，同时提升稳定性与信号传播。所有现代语言模型都把层归一化移出残差流（"每个人都把层规一化移到了残叉流之外"；唯一例外是 OPT-350M 用了残差流内的后归一化）。

### RMSNorm 与 LayerNorm

LayerNorm 对激活减去均值、除以方差、再缩放回来；RMSNorm 不减去均值或偏置项，只做缩放。理论上层规一化"比RAMS norm更具表达力"，但 RMSNorm 实际"表现效果和层规一化一样好"，且因为归一化操作算术强度低、内存搬运占比高（计算量占比 0.17%、小模型上运行时占比可达 25%），RMSNorm 减少内存移动从而带来免费性能提升。配套做法是去掉线性层与归一化层里的偏置项（转录称大多数实现实际上完全去掉了偏置）。

### 注意力块：QKV、多头、mask

标准注意力流程：预层归一化 → 乘以 QKV 权重得到 q、k、v → q、k 矩阵乘法 → softmax → 与 v 相乘得到加权平均。多头注意力的标准做法是让"经验法则就是注意力头的维度乘以头的数量"等于模型维度，即每个头维度 = D/H、总维度保持 D，这个比例在各模型中都在 1 左右，且是宽容超参。转录中未见对因果 mask 的展开讨论（见"待验证项"）。块内串行（先注意力再 MLP）是主流；并行块（GPT-J 提出、PaLM 使用，"你只需要把MLP和注意力层的输出加在一起"）因能共享归一化、融合矩阵乘法而带来系统收益，但近两年已不再流行。

### 前馈网络与激活函数（GELU/SiLU/SwiGLU/GeGLU/ReGLU）

普通 FFN：X·W → 阈值（激活）→ 再投影。GELU 与普通激活的区别是"实际上唯一的区别是底部这里的一个小凹陷"，改变接近零处的梯度，GPT-3 用它训练成功。门控线性单元增加一个门控矩阵 V，把激活输出与 V·x 逐元素相乘再投影，如 ReGLU（门控用 ReLU）、GeGLU（门控用 GELU）、SwiGLU（门控用 Swish/SiLU）。"我认为几乎所有可信的现代语言模型"都使用某种 GLU；Google 系（Gemma、T5）"Google那边用的是GEGLU"，LLaMA/Palm 后代"而所有类似LAMA后代的模型都用的是SweagU"（转录对 SwiGLU 的误写）。GLU 多一个矩阵，需把 FFN 维度缩到 2/3 以保持参数量；参数匹配下 GLU 变体几乎总是比非 GLU 变体表现更稳定，是一种"免费胜利"。

### 位置编码：绝对 / 相对 / RoPE

"因为Attention在位置上是独立的"（只是内积），因此必须注入位置信息。"原始Transformer用的是正弦和余弦嵌入"；之后不少模型用绝对位置嵌入（"每个位置都有自己的不同的嵌入"）；Google 系 T5/Chinchilla 用相对位置嵌入（把向量直接加到注意力矩阵，而非加到词嵌入）。RoPE 是旋转位置编码，属于相对位置嵌入：词向量按位置旋转、成对坐标各自旋转不同角度，内积对绝对位置不变、无交叉项（"这些内积都将对绝对位置保持不便"，"不便"为 ASR 对"不变"的误写）。实现上根据序列的位置 ID 生成余弦和正弦角度、应用到查询和键上，且在注意力层执行而非最底层。

### 超参数：FFN 比率、头维度、长宽比、词汇量

- **FFN 比率**（FFN 首矩阵输出维度 / 模型维度）：共识是约 4（即隐藏维度的 4 倍）；GLU 缩到 2/3 后"这意味着你最终会得到大约2.67这样的数值"；LLaMA 因 MQA 省参把比率提到约 3.5（"任意乘以1.33得到大约3.5"）；T5 用了激进的 64 倍（异常值，后续 T5 v1.1 回到 2.5 倍）。Kaplan 2020 显示 2.6-4 是平坦盆地。
- **头维度**：头维度/模型维度 ≈ 1（即 head_dim = D/H），宽容。
- **长宽比（深度 vs 宽度）**：D/N ≈ 100，即每层约 100 宽度；极深模型难做流水线并行、极宽模型更易张量并行，100 是表达能力与系统利用率的折中。
- **词汇量**：单语约 3 万；多语言/生产模型约在十万到二十万之间；模型越大能处理词汇量越大（缩放趋势）。
- **权重衰减与学习率**：权重衰减在配合学习率衰减时（而非恒定学习率）收敛到明显更好的最小值；权重衰减更接近优化干预而非正则化，且与优化器以反直觉方式相互作用。

### 稳定性技巧：Z-loss 与 QK-norm

Softmax 的指数运算与除法是稳定性风险点（"Softmax有两个对稳定性非常不利的因素"），模型中两处 softmax（输出侧与注意力内）都危险。输出侧用 Z-loss：在损失中加 `log z` 平方惩罚，把归一化项拉回 0（"惩罚你的logz偏离0的程度"），基于 softmax 过参数化、可加常数平移的特性；该技巧由 Jacob Devin 等在 2014 年左右推广。注意力侧用 QK-norm：在 q、k 相乘前加 RMSNorm，使矩阵乘法输入尺度一致（"它们的尺度始终会保持在一左右"），防止注意力退化；qknorm 源自 multimodal 领域，现已是常见干预、不影响性能，反而让你能稍微提高学习率（原文："因为你可以稍微提高学习率"）。更强的干预是 logits softcapping（Google/JaMA 系），会牺牲表达能力（"你在Mobself里永远无法表达超出一定范围的资讯信号"，"Mobself"为 ASR 误写）。

### 注意力变体：GQA / MQA / 滑动窗口（简述）

原始 Transformer 每个头有独立 q、k、v；MQA 让所有头共享一组键/值（KV 缓存显著变小、减少内存访问，但损失表达能力）；GQA 减少键/值头数量而保持查询头数量，可调 Key/Value Heads 比例，推理成本非常低而"性能却几乎与完整的多头注意力相同"，故现几乎全模型采用。滑动窗口/带状矩阵注意力把"关注全部过去"变成"关注固定窗口"，常与全局注意力交替使用（GPT-3 系列、Gemma 等），用以处理长上下文。GQA 的动机是部署期推理成本（"它通过减少注意力头的数量来节省推理成本"）。
